# 小红书站点经验

## 访问策略

- 用户近期反馈：未登录时多数笔记内容难以读取，评论更难读取。将此作为选择浏览器的经验线索，实际是否需要登录仍以目标页面为准。
- 用户需要一篇指定笔记的完整正文、图片说明或评论时，搜索工具只用于发现候选笔记，随后直接用已配置的本地外部浏览器（CDP）打开原帖；不要先对每个笔记重复尝试静态抓取。
- 用户只需要发现候选笔记或了解是否存在相关讨论时，可先用公开网页搜索。搜索标题和摘要不等于已读笔记正文或评论。
- 打开目标页时直接确认所需正文和评论是否出现。页面明确跳转登录或要求登录才能读取目标内容时，请用户在该外部浏览器手动登录后继续读取；403、空白、加载失败或页面壳不能单独证明登录失效。
- 不得读取 cookie、存储、密码或会话文件。
- 若登录后仍无法取得笔记或评论，记录实际可读范围，改用其他来源补充；不把搜索摘要、转载或笔记标题表述为已核实的一手体验。

## 内容核实

- 核对笔记日期、产品/服务版本、使用时长、地区和具体使用条件。单个笔记只能作为个案，不据此推断总体口碑或统计比例。
- 对产品与政策结论，分别寻找官方规格或规则及其他独立体验；作者的个人经历、推广内容和未经验证的说法应清楚区分。
- 评论或讨论任务必须实际读取相关评论；评论数或页面显示的“评论”入口不代表评论文本已取得。
